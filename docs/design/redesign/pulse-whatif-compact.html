03 · The hand-off — pressure-test in chat
One grammar: statement → question → number Every pulse keeps the shipped voice (italic, 13px, SignalRow shell) and gains the projection row’s trailing gold clause — no buttons, no new chrome. The clause IS the affordance, exactly as “See what moves it →” already works today.
Tense-matched doorways The band pressure-tests today (chips built from the vitals the sentence named), Worth knowing asks the detector’s canonical what-if (housing −15% — the shock model the app already uses), Markets asks the past-tense counterfactual the engine already computes.
Markets becomes yours The cron already stores an estimated euro impact per story (impact_eur) — the UI just never rendered it. A quiet tabular figure (“≈ +€85”) on the collapsed row makes the news personal at a glance; the expanded row names the holding behind it.
Freshness without noise A small gold “new” on the dateline, only when today’s sentence differs from the one last seen. No badges, no counters — the cache already knows.
Compact: one line per pulse Collapsed carousels clamp to a single line (title only, dots inline); row padding tightens 11→9px; the projection sentence is shortened. The family costs roughly a third less height, so the first vital rows are visible without scrolling.
Motion budget: one settle-in Band, then rows, rise 4px in sequence — ≤0.6s total, play-once per session, plain fade under reduced-motion. Nothing else moves; no auto-advancing carousels, no count-ups. Within the brand guardrails in mobile-wow-moments.md.
